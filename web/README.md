# 📦 Projeto Web

## 🧰 Versões Utilizadas

Este projeto foi desenvolvido utilizando as seguintes versões:

- **Angular:** 21.1.4
- **Node.js:** 24.13.1

> ⚠️ Recomenda-se utilizar exatamente essas versões para evitar problemas de compatibilidade.

---

## 🚀 Como Executar o Projeto

### 1️⃣ Instalar as dependências
Execute o seguinte comando para instalar as dependências antes de executar a apliação:
```
npm i
```

### 2️⃣ Iniciar o servidor de desenvolvimento
Para executar o projeto em ambiente de desenvolvimento, execute o comando

```
npm start
```
